# Static Dialog Binaries

This repository hosts pre-compiled, fully standalone `static-pie` binaries of `text-based user interface tools` built against `musl`. 

### Why?
I am mostly using this for archival purposes for future projects.
Standard `dialog` packages rely on dynamic host libraries (`glibc`/`ncurses`). These binaries are fully self-contained and designed to run flawlessly across any x86_64 Linux environment, minimal server, or micro-container (like Alpine Linux).
